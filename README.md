# GPT — Teste Plus

Repositório usado para anotar e organizar experimentos com ferramentas de inteligência artificial.

## Escopo

Os testes ainda não foram reunidos em uma aplicação reproduzível. Este espaço não representa um produto pronto nem uma integração oficial.

## Registro dos experimentos

Quando novos testes forem adicionados, documentar o objetivo, os requisitos, o procedimento para reproduzir e os resultados observados. Nunca incluir chaves de API, credenciais ou dados pessoais nos exemplos.

## Linguagens

Ainda não há código-fonte versionado neste repositório; o GitHub não tem linguagens para exibir.
